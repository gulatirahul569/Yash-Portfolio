# Yash Sharma — Corporate Legal Portfolio

A premium, responsive Next.js portfolio based on the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## First things to customize

1. Replace the hero photo placeholder in `app/page.js` with a professional portrait.
2. Add the actual resume PDF as `public/yash-sharma-resume.pdf` so the Download CV links work.
3. Update the text, colors and sections as needed.
4. Update `app/layout.js` metadata for the final site title/description.
5. Update the LinkedIn, email and phone details if the contact information changes.

## Deploy

This project can be deployed directly to Vercel after pushing it to GitHub.
